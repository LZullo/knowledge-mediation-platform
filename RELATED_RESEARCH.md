# Relação com a pesquisa

Este repositório é a **plataforma de software** (`knowledge-mediation-platform`).

O experimento científico controlado (benchmark congelado, campanhas, estatística, protocolo do artigo) vive em:

| | Plataforma | Estudo |
|--|------------|--------|
| **Nome institucional** | `knowledge-mediation-platform` | `knowledge-mediation-study` |
| Papel | RAG, API, embeddings, rerank, pgvector, Ollama | Artefato experimental + evidência |
| Evolui como | Software | Protocolo congelável por paper |

### Paths de execução (legado estável)

Para não quebrar a campanha do artigo, a descoberta da plataforma pelo estudo continua a aceitar:

- `RCC_TCC_PROJECT_ROOT`, ou  
- sibling `../tcc-project` (default no código — **não alterado**).
